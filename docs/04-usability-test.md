# NEURAL — 사용성 테스트 키트 (v1.0 출시 전)

> **목적:** 제품 명세 §8의 성공 지표 중 사람이 직접 해야 하는 항목을 측정하고, v1.0 출시 전에 치명적인 문제를 찾는다.
> **소요:** 참가자 1명당 25분 × 5명. 진행자 1명(가능하면 기록자 1명 추가).

## 3. 준비

- 노트북(내장 GPU, 1080p 이상), 최신 Chrome. **처음 방문 상태**로 시작: 시크릿 창 또는 사이트 데이터 삭제.
- 화면 녹화 + 음성 녹음(동의 받기). 시간 측정용 스톱워치.
- 사전 안내 문구(그대로 읽기):
  > "오늘은 저희가 아니라 이 사이트를 시험하는 자리예요. 막히면 그건 사이트 문제니 편하게 말해 주세요. 생각나는 걸 소리 내서 말하면서 진행해 주시면 큰 도움이 돼요."

## 4. 과제 (진행자는 힌트를 주지 않는다 — 3분 넘게 막히면 "다음으로 넘어갈게요")

| # | 시작 화면 | 과제 문구 (그대로 읽기) | 관찰 포인트 |
|---|---|---|---|
| 1 | 랜딩 `/` | "이 사이트가 뭘 하는 곳인지 30초 동안 둘러보고 말해 주세요." | 슬로건·데모를 이해하는지, CTA를 찾는지 |
| 2 | (참가자 선택) | "신경망이 뭔가를 배우게 해 보세요." | 환영 대화상자에서 무엇을 고르는지, ▶까지 걸린 시간 **(Q2)** |
| 3 | 연구실 | "화면 가운데 그림에서 동그라미 하나가 무슨 계산을 하는지 확인해 보세요." | 뉴런 클릭까지 시간 **(Q1)**, 인스펙터를 읽는지 |
| 4 | 연구실 | "가장 중요한 연결은 어디예요? 그리고 이 뉴런(진행자가 가리킴)은 켜져 있나요?" | 굵기·색 해석 **(Q4)** |
| 5 | 연구실 | "학습을 처음 시작했을 때 그림이 어땠는지 다시 보고 싶어요. 방법을 찾아보세요." | 학습 곡선 누르기를 발견하는지 **(Q5)** |
| 6 | `/learn/` → 레슨 2 | "배우기 페이지에서 '선 하나로 안 될 때' 레슨을 끝까지 해 보세요. 끝나면 왜 은닉층이 필요한지 설명해 주세요." | 레슨 진행 막힘 지점, 설명 내용 **(Q3)** |
| 7 | 연구실 | "지금 실험을 친구에게 보내고 싶어요." | 내 실험 → 링크 복사를 찾는지 |

## 5. 사후 질문

5점 척도(1 = 전혀 아니다, 5 = 매우 그렇다) **(Q6)**:
1. 화면에서 무엇을 봐야 할지 알기 쉬웠다.
2. 신경망이 어떻게 학습하는지 전보다 더 잘 이해하게 됐다.
3. 다음에 또 써 보고 싶다.
4. 다른 사람에게 추천하고 싶다.

열린 질문:
- 가장 헷갈렸던 순간은 언제였나요?
- 가장 "아하" 했던 순간은 언제였나요?
- 하나만 바꿀 수 있다면 무엇을 바꾸고 싶나요?

## 7. 결과 정리

1. Q1~Q6를 표로 모아 통과/미달을 표시한다.
2. 막힌 지점을 "누가, 어디서, 왜"로 묶고 심각도를 매긴다: **치명**(과제 실패) · **큼**(30초 이상 지연) · **작음**(망설임).
3. 치명·큼 항목은 v1.0 전에 고치고, 고친 뒤 해당 과제만 2명에게 다시 확인한다.
4. 결과를 `03-development-plan.md §6 진행 기록`에 요약해 남긴다.

## 8. 실기기 성능 측정 (함께 진행)

CI는 소프트웨어 렌더러라 FPS가 의미 없다(§6 진행 기록 참고). 참가자 노트북 중 1대에서:

1. 연구실 → 고급 설정 없이 은닉층 6개 × 뉴런 16개, 데이터셋 Spiral, 속도 "최대"로 학습.
2. Chrome 개발자 도구 → Rendering → **Frame Rendering Stats** 켜고 30초간 FPS 기록.
3. 목표: 평균 60fps, 최소 45fps (명세 §8). 미달 시 기기 사양과 함께 기록.
