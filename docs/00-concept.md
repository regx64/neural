## 1. 프로젝트 개요

**NEURAL**은 인공신경망의 구조와 학습 과정을 3D 시각화 및 직접 조작을 통해 탐험할 수 있는 인터랙티브 웹사이트다.

일반적인 AI 소개 페이지나 정적인 신경망 그림에서 벗어나, 사용자가 신경망을 관찰하고 직접 실험하면서 내부 계산이 어떻게 결과로 이어지는지 이해하도록 돕는다.

- **프로젝트 유형:** 기술력 과시형 인터랙티브 웹사이트
- **핵심 분야:** 인공지능, 머신러닝, 3D 시각화, 웹 그래픽스
- **핵심 방향:** 실제 계산과 시각적 표현을 연결
- **주요 사용자:** AI·컴퓨터공학에 관심 있는 사람, 학생, 개발자, 기술 시연을 원하는 사용자

## 2. 기획 배경 및 목적

신경망은 보통 수식, 코드 또는 정적인 다이어그램으로 소개된다. 이 방식만으로는 입력 데이터가 각 층을 통과하며 어떻게 처리되고, 학습 과정에서 모델이 어떻게 변하는지 직관적으로 파악하기 어렵다.

NEURAL은 신경망을 **직접 탐험하고 실험할 수 있는 공간**으로 표현해 이러한 장벽을 낮춘다. 동시에 3D 렌더링, 인터랙션, 머신러닝 계산을 하나의 웹 경험으로 통합해 웹 기술과 소프트웨어 구현 역량을 보여 주는 것을 목표로 한다.

## 3. 핵심 콘셉트

사용자가 3D 공간에 표현된 신경망을 자유롭게 탐색하고, 뉴런과 연결을 선택해 정보를 확인하며, 직접 데이터를 넣어 학습 결과를 관찰한다.

시각 효과는 단순한 장식이 아니다. 뉴런의 활성화, 연결선의 가중치, 신호의 흐름 등은 가능한 한 실제 모델의 계산 상태를 반영한다.

### 디자인 방향

- 어두운 배경을 기반으로 한 미래적·과학적 분위기
- 뉴런과 연결을 강조하는 절제된 발광 효과
- 정보가 많은 화면에서도 읽기 쉬운 패널과 타이포그래피
- 과도한 장식보다 실제 조작과 데이터 표현을 우선
- 3D 시각화와 분석용 UI가 조화를 이루는 구성

## 4. 주요 기능 구상

### 4.1 3D 신경망 탐험 (Neural Explorer)

- 신경망의 층, 뉴런, 연결을 3D 공간에 표현
- 카메라 이동·회전·확대 및 축소
- 뉴런이나 연결을 선택해 관련 정보 확인
- 활성화 값과 가중치에 따른 시각적 변화

### 4.2 신경망 학습 (Live Training)

- 예제 데이터셋을 선택해 학습 실행
- 학습 진행에 따른 손실과 정확도 변화 표시
- 학습 결과가 신경망 시각화에 반영되도록 구성
- 학습 중지 및 재시작 등 기본 제어 제공

### 4.3 실험 공간 (Experiment Lab)

- 데이터 포인트를 추가하거나 위치 변경
- 층과 뉴런 수 등 기본적인 네트워크 설정 변경
- 설정 변화에 따른 분류 결과 비교
- 학습된 모델의 결정 경계 시각화

### 4.4 계산 과정 확인 (Computation Inspector)

- 선택한 뉴런의 입력값, 가중치, 편향, 활성화 값 확인
- 순전파 과정의 주요 계산 단계 표시
- 입력에서 출력까지 신호가 전달되는 흐름 추적

### 4.5 학습 상태 기록 및 재생 (Time Travel)

- 학습 도중 주요 시점의 모델 상태 기록
- 이전 상태를 불러와 결과 비교
- 학습 중 특정 시점의 모델을 다시 살펴볼 수 있도록 구성

> 위 기능은 초기 구상이며, 구현 난이도와 개발 일정에 따라 우선순위를 조정한다.

## 5. 차별화 방향

NEURAL의 차별점은 **실제 신경망 계산과 3D 시각화가 연결되어 있다는 점**이다.

- 단순한 애니메이션이 아닌 실제 모델 상태를 반영하는 시각화
- 신경망 구조를 관람하는 데서 끝나지 않고 직접 수정하고 실험하는 경험
- 모델의 결과뿐 아니라 내부 계산 과정을 확인할 수 있는 기능
- 학습 상태를 기록하고 비교해 모델의 변화를 탐색하는 기능
- 브라우저에서 접근할 수 있는 통합형 AI 학습·탐험 공간

## 6. 예상 기술 방향

세부 기술은 구현 단계에서 검토하되, 초기에는 다음 기술을 후보로 고려한다.

| 영역 | 후보 기술 및 방향 |
|---|---|
| 웹 애플리케이션 | Next.js, React, TypeScript |
| 3D 시각화 | Three.js, React Three Fiber |
| 신경망 계산 | 작은 완전연결 신경망(MLP)을 직접 구현 |
| 차트 및 분석 UI | Canvas, SVG 또는 차트 라이브러리 |
| 성능 개선 | Web Workers를 통한 학습 연산 분리 |
| 데이터 저장 | 초기에는 브라우저 로컬 저장을 우선 검토 |

초기 버전은 작은 신경망과 간단한 데이터셋을 중심으로 구성한다. 대규모 모델 학습이나 GPU 가속은 핵심 경험을 검증한 뒤 필요성에 따라 확장한다.

## 7. 초기 개발 범위

첫 번째 버전에서는 모든 기능을 한꺼번에 구현하기보다 프로젝트의 핵심 가치를 확인할 수 있는 범위에 집중한다.

**초기 버전의 핵심 범위**
1. 3D 신경망 구조 시각화
2. 뉴런 및 연결 선택과 정보 확인
3. XOR 등 작은 예제 데이터셋을 이용한 신경망 학습
4. 학습 결과와 활성화 값의 시각화 연동
5. 기본적인 학습 진행 상태 표시

**후속 확장 후보**
- 사용자 정의 데이터셋과 네트워크 구조
- 결정 경계 편집 및 실험 비교
- 학습 상태 기록·복원
- 더 큰 모델과 GPU 연산 지원
- 실험 저장 및 공유 기능

## 8. 기대 효과

- 신경망의 구조와 학습 원리를 직관적으로 탐색할 수 있다.
- 실제 계산과 시각화를 결합해 기술적 완성도를 보여 줄 수 있다.
- 3D 그래픽스, 인터랙션, 머신러닝, 웹 애플리케이션 개발 역량을 하나의 프로젝트에서 다룰 수 있다.
- 향후 교육용 도구 또는 확장 가능한 인터랙티브 연구실로 발전시킬 수 있다.

## 9. 성공 기준

초기 버전은 다음 기준을 중심으로 평가한다.

- 신경망 구조를 쉽게 탐색하고 각 구성 요소의 정보를 확인할 수 있는가?
- 학습 실행에 따라 실제 모델 파라미터와 결과가 변하는가?
- 시각화가 실제 계산 상태를 일관되게 반영하는가?
- 사용자가 데이터나 설정을 바꾸고 결과 차이를 관찰할 수 있는가?
- 일반적인 노트북 환경에서 조작과 화면 표시가 원활하게 동작하는가?

## 10. 한 줄 정의

**NEURAL은 인공신경망을 3D 공간에서 탐험하고, 직접 학습시키며, 내부 계산 과정을 확인할 수 있는 인터랙티브 AI 연구실이다.**
